## Task 1 — Project Setup

### Learned

- Git tracks changes and project history.
- GitHub hosts the remote repository.
- `.git/` contains Git's internal repository data.
- `git add` stages changes.
- `git commit` records a snapshot.
- `git push` sends commits to GitHub.

### Commands Used

```bash
mkdir portfolio
cd portfolio
git init
git status
git add
git commit
git log
git remote
git push
